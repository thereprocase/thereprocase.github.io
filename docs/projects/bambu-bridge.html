Bambu Bridge

A local P1S printer bridge with a browser dashboard, 3D print-progress viewer, and Home Assistant integration.

AGPL source release · mock-tested; current firmware acceptance remains

PROJECT RECORD

Connect to your own printer over the LAN with its access code. The bridge shares MQTT, file-transfer, and camera connections among browser and API clients. The AGPL source release includes installation instructions, upstream notices, and firmware compatibility limits.

What it includes

  • Browser dashboard and 3D print-progress viewer.
  • HTTP and WebSocket API with Home Assistant integration and add-on source.
  • LAN and Developer Mode requirements, source access, and validation records.
