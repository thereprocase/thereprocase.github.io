BellCurve

An Android practice workspace with intonation analysis, metronome, drone, pitch pipes and a recording deck.

Public source · Android / Expo 56

PROJECT RECORD

The current local Android branch brings pitch feedback and practice tools together. This public source export uses a new application identifier and retains third-party audio and font licenses.

What it includes

  • Transposition-aware tuner and note statistics.
  • Configurable metronome, drone and pitch pipes.
  • Local recording deck and explicit sharing.
