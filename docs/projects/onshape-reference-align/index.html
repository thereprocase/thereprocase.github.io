Reference Align for Onshape

Scale and rotate reference images using distances and directions you already know.

Desktop downloads · Windows, macOS, and Linux

PROJECT RECORD

A local companion app gives you a precise image picker and sends the resulting calibration to Onshape. Separate scale and rotation pairs help when the best known distance and direction are in different parts of an image.

What it includes

  • Zoom, pan, a loupe, and subpixel point selection.
  • Separate pixel pairs for scale and rotation.
  • Packaged launchers, setup instructions, and backups before feature updates.
