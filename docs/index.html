EXTRUSION WIDTH AS A TYPE DESIGN PARAMETER

Fillaprint

Nominal strokes and minimum clear gaps both use two extrusion widths. That gives the lettering and its surrounding material the same minimum feature size—a useful constraint for small multicolour labels.

Try the actual fonts, calculate a reference print size, or inspect the glyph geometry. Proportional, tabular-figure and monospace families are available under the SIL Open Font License.
