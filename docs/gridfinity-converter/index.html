Fit and replacement notes

Screw holes fit within the available floor by default. The result shows the actual depth; choose Exact depth under Hardware dimensions to require a fixed depth.

Male feet use a 4.75 mm profile above the bottom. Female sockets use a 5 mm cavity measured inward from the rim. Replacement depth bounds the edited region; magnet and weighted floors extend it when needed. Deeper supports remain unchanged.

Positive = tighter fit: larger male feet or smaller female sockets. Negative = looser fit. Applied per side; 0.05 mm changes total width by 0.10 mm. Type hundredths; arrows step by 0.05 mm. Range: −0.50 to +0.20 mm per side.

Export options, checks and format details

Mesh output · STL and 3MF

Default export uses the detected base-down orientation. 3MF contains the selected part and a conversion report, without printer settings. STEP and BREP inputs preserve CAD surfaces through native solid operations and provide validated BREP export. STEP translation is validated separately when requested. CAD mesh exports start at 0.01 mm deviation and adapt automatically for large models; the actual value is recorded in the conversion report. Source colors, textures, assembly structure and CAD feature history are not retained.

How detection works and its limits

Automatic detection checks male feet and female sockets at several depths. Only complete cells on a 42 mm grid are selected. Review the orientation and selected cells before converting. Socket replacement changes only the selected cell regions; deeper supports remain intact. Positive friction makes male feet larger or female sockets smaller.
